# bpl_auction

A feature-rich, real-time online auction and bidding application built to deliver a seamless buying and selling experience. Users can explore live auctions, place competitive bids in real time, and list their own items for auction.

## ✨ Key Features

- **🔒 Secure User Authentication:** Register/Login via Email or Social accounts.
- **⚡ Real-Time Live Bidding:** Place bids and see instant real-time price updates without refreshing.
- **⏱️ Auction Countdown Timer:** Live timers for ongoing auctions to keep buyers engaged.
- **➕ List Items for Auction:** Sellers can create new auction listings with item title, description, starting price, images, and end duration.
- **🔔 Real-Time Notifications:** Alerts for when a user is outbid or when an auction is ending soon.
- **📊 Bid History:** View the complete bidding history and current highest bidder for any item.
- **👤 User Profile & Dashboard:** Track active bids, won auctions, and items listed for sale.

---

## 🛠️ Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend / Database:** Firebase (Cloud Firestore, Authentication, Firebase Storage) / Node.js & MongoDB
- **State Management:** Provider / BLoC / GetX
- **Real-Time Data:** WebSockets / Firestore Snapshot Listeners
